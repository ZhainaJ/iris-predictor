# Iris Species Predictor & Explorer

A Shiny app that predicts the species of an iris flower (setosa, versicolor or virginica) from four measurements.

- **Live app:** https://ysco3m-zhaina-abdulla.shinyapps.io/iris-predictor/
- **Files:** `ui.R` (sliders, axis selectors, tabs with built-in documentation) and `server.R` (fits `MASS::lda` on the `iris` data and predicts from the slider values)

Course project for *Developing Data Products* (Johns Hopkins University, Coursera).
